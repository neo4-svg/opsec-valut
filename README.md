# opsec.py 🔒

Hey security‑paranoid folks 👋 — we know it's confusing to keep your fake stories, burner emails, and multiple personas straight. **opsec.py** is a pure Python3 tool that helps you split, store, and manage identities safely. No external libraries, no sudo, just clean JSON configs and a simple CLI to keep your personas compartmentalized.

---

## ✨ Features
- **[Persona profiles](ca://s?q=Persona_profiles_in_opsec.py)** → store multiple identities with name, email, and notes.  
- **[Add & delete](ca://s?q=Add_and_delete_personas_opsec.py)** → create or remove personas instantly.  
- **[List identities](ca://s?q=List_personas_opsec.py)** → see all stored personas at a glance.  
- **[Export](ca://s?q=Export_persona_opsec.py)** → output persona data in JSON or ENV format for integration.  
- **[Pure Python3](ca://s?q=Pure_Python3_identity_tool)** → no dependencies, cross‑distro friendly.  

---

## 🚀 Installation
Clone the repo and run with Python 3:

```bash
git clone https://github.com/neo4-svg/opsec-valut.git
cd opsec.py
python3 opsec.py --help
```
